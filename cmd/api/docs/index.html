Caveo

Stateless Argon2id password hashing and verification. Version {{VERSION}}.

OpenAPI spec: /docs/openapi.yaml. All responses are JSON, including errors.

The forms below post to this running instance. Use throwaway values instead of real passwords.

POST /hash

Generates a fresh random salt and returns a string of the form $argon2id$v=19$m=19456,t=2,p=1$salt$hash. Store that whole string. It contains the salt and the cost parameters, so no other columns are needed. 

curl -s localhost:8080/hash \
  -H 'Content-Type: application/json' \
  -d '{"password":"Password123!"}'

Status
Body

POST /verify

Parses the parameters out of the supplied hash and compares in constant time. A wrong password is 200 with {"match": false}. A malformed or out-of-range hash is 400. 

curl -s localhost:8080/verify \
  -H 'Content-Type: application/json' \
  -d '{"password":"Password123!","hash":"$argon2id$v=19$..."}'

Response

Status
Body

Responses

Status When
200 Hash created, or comparison completed (see match).
400 Body is not valid JSON, a field is missing, or the hash is malformed.
404 Unknown path.
405 Wrong method for a known path. Allow lists what it accepts.
500 Unexpected server error.
503 All Argon2 slots are busy. The response sets Retry-After: 1.

Operational endpoints

GET /healthz returns 200 while the process is running. GET /readyz returns 200 while serving and 503 once shutdown begins, so a load balancer can take it out of rotation before the server stops accepting requests.
